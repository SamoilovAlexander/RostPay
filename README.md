# RostPay
На всплывающем окне не хватает кнопки "Закрыть" или "ОК" для его закрытия и перехода в личный кабинет. 
Можно, конечно это сделать кнопкой "Esc" на клавиатуре, но не мешало бы ее сделать и в самом окне. 

Отсутствует подтверждение почты до окончания процесса регистрации, т.е. база данных может быть наполнена всяким шлаком 
с несуществующими почтами и (Я ТАК ДУМАЮ!!!) люди, просто меняя почту, могут продолжать пользоваться услугами сервиса, 
не платя за него. Но, опять же, я не знаю бизнес-идеи, которой руководствовались при создании данного приложения.

Непонятно, зачем нужен секретный ключ. Зачем он нужен при входе. Это ведь тоже статические данные. 
Достаточно надежного пароля и (при необходимости) двухфактурной аутентификации. 
А вот при создании пароля не хватает проверки его на надежность (например, на наличие верхнего и нижнего регистра, 
цифр, спецсимволов, минимальной длины). В тоже время для удаления учетной записи секретный ключ не требуется.

У меня нет доступа к документации по этому проекту, соответственно я не знаю ограничения полей при регистрации 
и не смог написать негативные тесты на невалидные данные.
